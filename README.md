# King of Burgers
Учебный командный проект по разработке 2D-игры на WPF (C#, .NET). Игра представляет собой локальный мультиплеер на двоих: игроки по очереди роняют ингредиенты на свои булочки с помощью раскачивающейся клешни, набирают очки за точность и соревнуются, кто первым достигнет заданного количества очков.

# Игровая механика
В основании — нижняя булочка. Сверху клешня раскачивается над бургером и сбрасывает ингредиенты.

Игра на двоих: на экране два бургера, у каждого свой счёт.

Ход по очереди: активный бургер на переднем плане, неактивный затухает (уходит на задний план).

Амплитуда и скорость раскачивания клешни растут с высотой бургера — чем выше, тем сложнее.

Очки начисляются в зависимости от точности попадания относительно центра: идеальное попадание — максимум, край — меньше.

Мисклик (клик не в свой ход / сброс в пустоту) — штраф.

Побеждает первый, кто набрал N очков (конфигурируемая константа).
